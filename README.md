## Overview

**CONVERTinator** is a highly optimized, lightweight console-based currency converter. It bypasses conventional exchange rate limitations by building a local and global currency graph, calculating accurate median rates across multiple financial APIs.

## Features

* **High Performance:** Asynchronous and parallel polling (`Task.WhenAll`) ensures response times match the fastest available server.
* **TRAVEL Mode:** Automatic geolocation-based currency detection. Instantly provides local rates and bordering countries' currencies without unnecessary clutter.
* **BUSINESS Mode:** Deep financial analytics including cross-rate calculations via base currencies (USD/EUR) and global/regional median evaluation.
* **Smart Architecture:** Strict categorization of data sources by global regions.

## Technologies

* C# / .NET
* Asynchronous Programming
* On-the-fly JSON/XML Parsing
